# 酷狗概念版每日 VIP · Loon

从已登录的酷狗概念版保存签到配置，每天核对领取记录后领取当天 VIP。支持单账号，默认每天设备本地时间 **06:00** 执行。

## 文件

| 文件 | 用途 |
| --- | --- |
| `kugou-concept-vip.plugin` | Loon 插件、定时任务及 HTTPS 解密规则 |
| `capture.js` | 从 App 成功响应中校验签名，保存查询及领取所需配置 |
| `claim.js` | 查询记录、手动或定时领取、后台更新登录凭证 |
| `test/native.test.cjs` | 使用模拟 Loon API 的本地回归测试 |

## 已安装用户升级

更新插件和远程脚本即可。已有的 `kgcv.native.v1` 接口配置和 `kgcv.claim.v1` 防重复领取状态继续使用，**无需重新捕获或测试领取**。

日常保持“启用自动领取”和“后台凭证更新”开启，“配置捕获”关闭。Loon 可能保留旧版“启用凭证捕获”的开关值，升级后请检查“配置捕获”是否已关闭。领取时间仍沿用已保存的参数，需要每天 06:00 执行时设为 `0 6 * * *`。

独立诊断脚本、签名报告和旧 Android 兜底流程已移除；原“测试 Web 领取”功能合并到“手动核对并领取 VIP”的首次配置流程。

## 首次安装或切换账号

1. 在 Loon 中添加插件：

   ```text
   https://raw.githubusercontent.com/changeCat/kugou-concept-vip-loon/main/kugou-concept-vip.plugin
   ```

2. 使用 Loon 3.5.1 (983) 或更新版本，安装并信任 HTTPS 解密证书，启用插件及其 MitM 域名。
3. 保持“启用自动领取”关闭，开启“配置捕获”，打开已登录的**酷狗概念版** VIP 领取记录页面。
4. 收到查询配置已保存的通知后，关闭“配置捕获”。可运行“仅查询 VIP 记录”确认查询正常。
5. 运行“手动核对并领取 VIP”。已有领取配置时直接复用；缺少领取配置时，使用已验证的 Web 查询会话领取当天 VIP，仅在业务响应成功后保存领取配置。如果当天已领，等次日再完成此步骤。
6. 确认领取成功并核对 App 权益后，开启“启用自动领取”。

切换账号或设备身份变化时，先关闭自动领取，再按上述步骤重新捕获和验收。

## 日常使用

- **自动领取**：默认每天 06:00，要求已保存查询及领取配置。
- **手动核对并领取 VIP**：立即检查并领取；首次使用时也负责保存成功的 Web 领取配置。
- **仅查询 VIP 记录**：只查询，不提交领取，不改变当天领取状态。
- **后台凭证更新**：打开概念版时监听普通请求，同一 App、账号和设备的新 Token 通过只读查询验证后，更新已有配置。无需特意进入 VIP 页面；App 要求登录时先重新登录。监听会产生 Loon 运行记录。

## 领取规则与常见问题

- 先查询月度记录，只有明确显示今天未领取时才提交一次领取。当天已确认成功时直接跳过。
- 发出领取请求前保存待确认状态。超时、业务失败或中断后，当天只复查记录，不重复提交；请到 App 查看实际权益。
- 查询失败、记录结构无法识别或配置不完整时停止领取。错误详情会脱敏后写入通知和日志。
- 凭证更新只接受同账号、同设备的新 Token，验证失败保留原配置；每分钟最多验证一次。切换账号、设备变化或配置失效时需重新捕获。
- 未收到配置保存通知时，检查 HTTPS 解密、插件与“配置捕获”开关，并确认进入了概念版 VIP 记录页面。
- 配置和凭证只保存在手机的 Loon 本地存储；不要公开 Token、Cookie、完整请求或脚本存储内容。

## 本地测试

